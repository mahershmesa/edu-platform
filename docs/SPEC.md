# مواصفات منصة "أساس أكاديمي"

منصة تعليمية عربية للمعلمين والطلاب في العراق. يرفع المعلمون دوراتهم (دروس فيديو وامتحانات)، ويفتح الطلاب الدورات بأكواد يشترونها من المعلم، ويدفع المعلمون اشتراكاً للمنصة.

هذا الملف هو المرجع الثابت للمشروع. بُني من دراسة لوحة التحكم في النظام القديم (35 صورة)، ومن القرارات التي اتُّفق عليها.

---

## 1. القرارات المعتمدة

| الموضوع | القرار |
|---|---|
| نطاق المرحلة الحالية | **الموقع فقط**: لوحة المدير، ولوحة المعلم، ومنصة الطالب. تطبيق الجوال لاحقاً على الخادم نفسه. |
| العملة | **دينار عراقي فقط** (أعداد صحيحة بدون كسور). |
| دفع الطالب | **بالأكواد فقط**. لا يوجد دفع إلكتروني في هذه المرحلة. |
| التسجيل | بالبريد أو برقم الهاتف وكلمة مرور. **بدون رمز تحقق** حالياً، مع ترك مكان لإضافته لاحقاً. |
| الفيديو | روابط يوتيوب، تُعرض داخل مشغّل خاص يخفي الرابط، مع **علامة مائية متحركة** تحمل اسم الطالب ورقمه. |
| منع مشاركة الحساب | **جهازان كحد أقصى** لكل طالب، والمدير يستطيع إعادة التعيين. |
| اشتراك المعلم | فاتورة مستحقة بتاريخ استحقاق، و**مهلة سماح 7 أيام**، ثم إيقاف تلقائي. |
| الاستضافة | تُحدَّد لاحقاً. يُجهَّز المشروع ليعمل على خادم خاص (Docker) أو خدمة جاهزة. |

## 2. أنواع المستخدمين

| النوع | الوصف |
|---|---|
| **مدير النظام** | كل الصلاحيات، بما فيها إدارة الأدوار والموظفين. |
| **موظف إدارة** | يدخل لوحة المدير بصلاحيات يحددها **الدور** المسند إليه (دعم، مالية، محتوى...). |
| **معلم** | يدير دوراته ودروسه وامتحاناته وأكواده، ويرى طلابه وفواتيره. |
| **طالب** | يتصفح، ويفتح الدورات بالأكواد، ويشاهد الدروس، ويؤدي الامتحانات. |

**صفحة دخول واحدة** للجميع، ثم يوجَّه كل مستخدم إلى واجهته.

## 3. الأدوار والصلاحيات

- الدور له: اسم، ومعرّف، ووصف، وحالة، ومجموعة صلاحيات.
- **أدوار نظامية** لا تُحذف: الدعم، والمالية، والمحتوى، ومدير كامل (كل شيء عدا إدارة الأدوار).
- **أدوار مخصصة** ينشئها مدير النظام ويحذفها.
- صفحة الأدوار متاحة لمدير النظام فقط.
- **أسماء الأقسام والصلاحيات تُعرض بالعربية** في الواجهة.

| الطلاب | عرض، تعديل، تغيير كلمة المرور، إعادة تعيين الأجهزة |
| الطلاب المشتركون | عرض |

| الفئات | عرض، إنشاء/تعديل، حذف |
| الأكواد | عرض، إنشاء/تعديل، حذف/تعطيل |
| فواتير المعلمين | عرض، تعديل |
| حالة المعلمين | عرض، تحديث |
| الإعلانات | عرض، إنشاء/تعديل، حذف |
| إعدادات التطبيق | عرض، تعديل |

## 4. لوحة المدير

**التصميم العام:**
- قائمة جانبية خضراء على اليمين يمكن طيّها، ومسار الصفحة، وبطاقة المستخدم.
- قائمة **"اختر معلم للعرض"** للدخول بصفة معلم.
- **تظهر في القائمة فقط الأقسام التي يملك المستخدم صلاحيتها.**

### 4.1 لوحة التحكم
- فلتر للفترة: آخر 7 أو 30 أو 90 يوماً.
- بطاقات: الدورات، الدروس، الطلاب، الطلاب المشتركون، المعلمون، الامتحانات، إيرادات اشتراكات المعلمين.
- قائمتا أحدث الدورات وأحدث الطلاب المسجلين.
- **كل الأرقام تُحسب بطريقة واحدة موحّدة.** في النظام القديم كانت الأرقام تختلف من صفحة لأخرى.

### 4.2 المعلمون
- **القائمة:** بحث بالاسم أو البريد أو الهاتف، والأعمدة: الصورة والاسم، البريد، الهاتف، الحالة، تاريخ الانضمام، عدد الدورات، عدد الفواتير، وقائمة إجراءات.
- **إضافة معلم وتعديله:** الاسم، البريد، الهاتف، كلمة المرور، الصورة، النبذة.
- **الإجراءات:** تعديل، إيقاف أو تفعيل، تغيير كلمة المرور، الدخول بصفته، عرض الملخص.
- **صفحة ملخص المعلم:**
  - بطاقة تعريف.
  - إحصائيات: الدورات، الطلاب، معدل الإكمال، الأرباح.
  - قائمة دوراته، وزر "الذهاب لواجهة المعلم".

### 4.3 الدخول بصفة معلم
- يفتح المدير لوحة المعلم كما يراها المعلم تماماً.
- **شريط ثابت** أعلى الصفحة: "أنت تتصفح كمعلم"، مع زر الخروج.
- **كل عملية تتم في هذا الوضع تُسجَّل** في سجل العمليات باسم المدير.

### 4.4 الطلاب
- **القائمة:** بحث، وفلتر بالحالة (نشط أو موقوف). الأعمدة: الاسم، البريد أو الهاتف، الحالة، عدد الاشتراكات، تاريخ التسجيل، آخر دخول، وقائمة إجراءات.
- **الإجراءات:** تعديل، إيقاف أو تفعيل، تغيير كلمة المرور، **عرض الأجهزة وإعادة تعيينها**، عرض الاشتراكات، وإضافة طالب يدوياً.

### 4.5 الطلاب المشتركون
- كل صف يمثّل اشتراك طالب في دورة: الطالب، الدورة ومعلمها، **نسبة التقدم**، تاريخ الاشتراك، الكود المستخدم.
- بحث بالطالب أو الدورة، وفلتر بالمعلم أو الدورة.
- **إلغاء الاشتراك.**

### 4.6 الدورات
- **القائمة:** الصورة، العنوان، المعلم، الفئة، السعر بالدينار، الطلاب، الدروس، الحالة، والإجراءات (عرض، تعديل، حذف).
- **النموذج:**
  - العنوان*، الوصف، السعر بالدينار*.
  - **المعلم***، ويُطلب فقط حين ينشئ المدير الدورة.
  - الفئة* و**الفئة الفرعية**.
  - صورة الدورة: رفع حتى 5MB (JPG أو PNG أو WebP)، والمقاس المقترح 800×600.
  - الحالة: مسودة، منشورة، مخفية.
- **نافذة التعديل تُملأ بكل القيم الحالية.** هذا كان خطأً في النظام القديم.

### 4.7 الفئات
- مستويان: فئة ثم فئات فرعية.
- لكل فئة: الاسم، الوصف، الأيقونة أو الصورة، فيديو تعريفي (اختياري، ويُتحقق من صحة الرابط)، الحالة، والترتيب.
- بطاقات قابلة للفتح والطي، وعدادات **صحيحة** للدورات والفئات الفرعية.

### 4.8 فواتير المعلمين
- **إنشاء فاتورة:** المعلم، المبلغ بالدينار (أو مجانية)، بداية الفترة ونهايتها، تاريخ الاستحقاق، والملاحظات.
- **يُتحقق من أن نهاية الفترة بعد بدايتها.** هذا كان خطأً في النظام القديم.
- **الحالات:**

  | الحالة | المعنى |
  |---|---|
  | مسودة | لم تُرسل للمعلم بعد. |
  | مستحقة | أُرسلت وتنتظر الدفع. |
  | مدفوعة | يسجّل المدير الدفع يدوياً مع التاريخ وطريقة الدفع. |
  | متأخرة | تلقائياً بعد تاريخ الاستحقاق. |
  | ملغاة | |

- بحث، وفلتر بالمعلم والحالة.
- **عرض التواريخ بشكل موحّد** في كل الصفحات.

### 4.9 حالة المعلمين
- بطاقات: الإجمالي، النشطون، الموقوفون، الفواتير المتأخرة.
- **القاعدة التلقائية**، وتعمل يومياً وعند الضغط على "مزامنة":
  - إن كانت للمعلم فاتورة متأخرة تجاوزت **7 أيام** بعد الاستحقاق يُوقف حسابه.
  - حين يدفع، يُفعَّل تلقائياً.
- **المعلم الموقوف:**
  - لا يستطيع إضافة دورات أو دروس أو أكواد، ولا يستطيع تعديلها.
  - يرى رسالة توضّح السبب.
  - **طلابه الحاليون يستمرون** في مشاهدة ما اشتروه.
- **إيقاف يدوي** منفصل عن الإيقاف التلقائي، ويحتاج تفعيلاً يدوياً.
- قائمة تفصيلية بالمعلمين وحالاتهم وسبب الإيقاف.

### 4.10 الأكواد
- **القاعدة:** الكود الواحد يُربط **بدورة أو أكثر لنفس المعلم**، ويُستخدم **مرة واحدة لكل طالب في كل دورة**.
- **إنشاء الأكواد بالجملة:**
  - الدورات المرتبطة* (اختيار متعدد).
  - العدد.
  - حد الاستخدام الكلي (الفارغ يعني بلا حد).
  - اسم المجموعة (مثلاً "دفعة مارس").
  - تاريخ انتهاء (اختياري).
- **شكل الكود:** 6 إلى 8 أحرف وأرقام سهلة القراءة، بدون الأحرف المتشابهة (0 وO و1 وI).
- **العرض:**
  - مجمّع حسب المجموعة، والأعمدة: الكود مع زر نسخ، الدورات، الاستخدام (مثلاً 3/10)، الحالة (نشط، معطّل، مستنفد، منتهٍ)، وتاريخ الإنشاء.
  - **الإجراءات:** تعديل، **عرض من استخدمه**، تعطيل، حذف (فقط إن لم يُستخدم).
  - **تصدير مجموعة** إلى Excel أو PDF للطباعة.
- فلتر بالمعلم والدورة، وبحث بالكود، وإحصائيات.

### 4.11 الإعلانات (شريط الصفحة الرئيسية)
- صورة، عنوان، وصف، رابط، ترتيب، حالة، وفترة عرض (اختيارية).

### 4.12 إعدادات التطبيق (التحديثات الإجبارية)
- لكل من أندرويد وآيفون: رابط المتجر، رقم الإصدار، ونوع التحديث (إجباري أو عادي).
- تُستخدم حين يُبنى التطبيق.

### 4.13 الموظفون
- الاسم، البريد، كلمة المرور، **الدور**، والحالة.
- **نماذج إنشاء الحسابات تمنع الملء التلقائي** من المتصفح.

### 4.14 الإعدادات العامة
- اسم المنصة وشعارها.
- مهلة السماح للفواتير (7 أيام).
- الحد الأقصى للأجهزة (2).
- معلومات التواصل التي تظهر للطلاب (واتساب، هاتف).

## 5. لوحة المعلم

**المعلم يرى بياناته فقط.** في النظام القديم كانت دروس وامتحانات معلمين آخرين تظهر.

| الصفحة | المحتوى |
|---|---|
| **لوحة التحكم** | الدورات، الدروس، التسجيلات، الطلاب، الفواتير (الإجمالي، المدفوعة، المتأخرة، وحالة آخر فاتورة)، أحدث التسجيلات، وأحدث الدورات. |
| **الدورات** | نفس نموذج المدير، بدون اختيار المعلم. |
| **الدروس** | قائمة ببحث وفلتر بالدورة، وإجراءات: نشر أو إلغاء النشر، تعديل، **إعادة ترتيب بالسحب**، حذف. |
| **الامتحانات** | انظر القسم 5.1. |
| **مكتبة الوسائط** | رفع ملفات بالسحب والإفلات (**حد أقصى للحجم**)، مجموعات، ملف عام أو خاص، معاينة، نسخ الرابط، حذف. |
| **الطلاب** | طلاب دوراته: الاسم، التواصل، الدورة، التقدّم، آخر نشاط. بحث وفلتر بالدورة. |
| **الأكواد** | نفس صفحة المدير، مقصورة على دوراته. |
| **الفواتير** | فواتيره وحالاتها وتفاصيلها، وتعليمات الدفع. |
| **الملف الشخصي** | الصورة، الاسم، النبذة، الهاتف، تغيير كلمة المرور، وإحصائيات للقراءة فقط. |

**نموذج إضافة درس:**
- رابط يوتيوب مع زر **"تحقق"** (يجلب العنوان والمدة تلقائياً إن أمكن).
- الدورة، العنوان، الترتيب، المدة، الوصف.
- **مرفقات** (ملف PDF من مكتبة الوسائط).
- **"درس مجاني"**: يظهر لأي زائر في صفحة الدورة دون كود.

### 5.1 الامتحانات
- يرتبط الامتحان بدورة، و**بدرس معين** إن أراد المعلم.
- **الإعدادات:**
  - العنوان، الوصف، المدة بالدقائق.
  - **درجة النجاح %**.
  - **عدد المحاولات المسموح**.
  - **ترتيب عشوائي** للأسئلة والخيارات.
  - **إظهار الإجابات الصحيحة** بعد الانتهاء (نعم أو لا).
  - الحالة.
- **أنواع الأسئلة:**
  - اختيار من متعدد بإجابة واحدة.
  - اختيار من متعدد بعدة إجابات.
  - صح أو خطأ.
- **لكل سؤال:** النص، **صورة اختيارية**، النقاط، والخيارات مع تحديد الصحيح منها.
- **النتائج:** قائمة محاولات الطلاب (الدرجة، النجاح، الوقت المستغرق).

## 6. منصة الطالب (الموقع العام)

**الصفحة الرئيسية:**
- شريط الإعلانات، والفئات، والمعلمون المميزون، وأحدث الدورات.
- كيف تعمل المنصة، وزر التواصل.

**التصفح:**
- **صفحة الفئة:** فئاتها الفرعية ودوراتها.
- **صفحة المعلم:** نبذته ودوراته.
- **صفحة الدورة:**
  - الصورة، الوصف، المعلم، السعر بالدينار، عدد الدروس ومدتها.
  - قائمة الدروس، وتشغيل **الدروس المجانية** مباشرة.
  - زر **"أدخل الكود"**.
- **بحث** عن الدورات والمعلمين.

**الحساب:**
- إنشاء حساب: الاسم، الهاتف أو البريد، كلمة المرور، والمحافظة (اختياري).
- الدخول بالهاتف أو البريد، ونسيت كلمة المرور.

**إدخال الكود:**
- من صفحة الدورة أو من صفحة "تفعيل كود".
- إن كان الكود يفتح عدة دورات، **يرى الطالب الدورات المتاحة ويختار** (أو تُفتح كلها حسب إعداد المجموعة).
- **رسائل واضحة:** كود غير صحيح، مستخدم مسبقاً، منتهٍ، معطّل.
- **حماية من التخمين:** حد لعدد المحاولات الخاطئة.

**المشاهدة:**
- **مشغّل الدروس:**
  - قائمة الدروس على الجانب، والدرس التالي والسابق.
  - "تم الإنهاء"، والمرفقات.
  - **علامة مائية متحركة** بالاسم ورقم الهاتف.
  - رابط يوتيوب لا يظهر للطالب.
- **الامتحان:**
  - عدّاد تنازلي، وحفظ تلقائي للإجابات، وتسليم تلقائي عند انتهاء الوقت.
  - صفحة النتيجة.

**صفحاتي:**
- **دوراتي:** الدورات المفتوحة مع نسبة التقدم و"أكمل من حيث توقفت".
- **الملف الشخصي:** البيانات، كلمة المرور، والأجهزة المسجلة.

**حد الأجهزة:**
- عند تجاوز جهازين تظهر رسالة توضّح الحد وطريقة التواصل مع الدعم.
- يمكن للطالب تسجيل الخروج من جهاز قديم بنفسه، مرة كل فترة.

## 7. البيانات الأساسية (مسودة)

| الكيان | أهم الحقول |
|---|---|
| المستخدم | الاسم، البريد، الهاتف، كلمة المرور (مشفّرة)، النوع، الدور، الحالة، الصورة، النبذة، آخر دخول |
| الدور والصلاحيات | الاسم، المعرّف، نظامي أم لا، الحالة، قائمة الصلاحيات |
| الجهاز / الجلسة | المستخدم، وصف الجهاز، بصمة، آخر نشاط |
| الفئة | الأب (للفرعية)، الاسم، الوصف، الصورة، الفيديو، الحالة، الترتيب |
| الدورة | المعلم، الفئة، العنوان، الوصف، السعر (دينار)، الصورة، الحالة |
| الدرس | الدورة، العنوان، الترتيب، المدة، الوصف، معرّف فيديو يوتيوب، مجاني، منشور |
| الاشتراك | الطالب، الدورة، الكود، الحالة، التاريخ |
| تقدّم الدرس | الاشتراك، الدرس، تم الإنهاء، آخر موضع |
| الكود | النص، المعلم، المجموعة، حد الاستخدام، عدد الاستخدامات، تاريخ الانتهاء، الحالة، الدورات المرتبطة |
| استخدام الكود | الكود، الطالب، الدورة، التاريخ (لا يتكرر الثلاثي نفسه) |
| الامتحان | الدورة، الدرس، الإعدادات |
| السؤال والخيار | النص، النوع، النقاط، الصورة، الترتيب، الخيارات وصحتها |
| المحاولة | الامتحان، الطالب، البداية، التسليم، الدرجة، النجاح، الإجابات |
| فاتورة المعلم | المعلم، الرقم، المبلغ، الفترة، الاستحقاق، الحالة، تاريخ الدفع وطريقته، الملاحظات |
| الإعلان | الصورة، العنوان، الوصف، الرابط، الترتيب، الحالة |
| الملف | المالك، الاسم، النوع، الحجم، المجموعة، عام أو خاص |
| إصدار التطبيق | المنصة، الرابط، الإصدار، إجباري |
| سجل العمليات | من، ماذا، على أي عنصر، متى، وهل في وضع الانتحال |

## 9. أخطاء النظام القديم التي يجب تجنّبها

1. **أرقام غير متطابقة** بين لوحة التحكم والصفحات الأخرى.
2. **ظهور دروس وامتحانات معلمين آخرين** في لوحة المعلم.
3. **نافذة تعديل الدورة لا تُملأ** بالسعر والتصنيف.
4. **لا تحقق من التواريخ** (فترة تنتهي قبل أن تبدأ)، **ولا من الروابط**.
5. **عملات مختلطة** (دولار ودينار وريال).
6. **أرقام مختلطة** (عربية وإنجليزية)، **وتواريخ معروضة بأشكال مختلفة**.
7. **صور دورات مكسورة** بلا صورة بديلة.
8. **رفع ملفات بلا حد أقصى للحجم.**
9. **ملء تلقائي** لبيانات المدير في نماذج إنشاء الحسابات.
10. **بريد وهمي** لمن يسجّل بالهاتف، بدل أن يكون الهاتف حقلاً مستقلاً.
11. **حالة المعلم متناقضة** بين صفحتين.
12. **أزرار غير مرئية** (أبيض على أبيض).
13. **أسماء صلاحيات بالإنجليزية** في واجهة عربية.
14. **كشف عنوان IP الخادم ورقم المنفذ** في روابط الدخول.

## 10. مراحل البناء

1. **الأساس:**
   - إعداد المشروع وقاعدة البيانات.
   - الدخول والتسجيل.
   - الأنواع والأدوار والصلاحيات.
   - هيكل اللوحات (القائمة الجانبية والشريط العلوي).
2. **لوحة المدير (المحتوى والمستخدمون):** المعلمون، الطلاب، الفئات، الدورات، الإعلانات، الموظفون، الأدوار.
3. **لوحة المعلم:** الدورات، الدروس، مكتبة الوسائط، الطلاب، الملف الشخصي، والدخول بصفة معلم.
4. **الأكواد والاشتراكات:** الأكواد، فتح الدورات، الطلاب المشتركون، فواتير المعلمين، الإيقاف التلقائي.
5. **الامتحانات:** المحرّر، وأداء الامتحان، والنتائج.
6. **منصة الطالب:** الصفحة الرئيسية، التصفح، المشغّل، العلامة المائية، حد الأجهزة، دوراتي.
7. **التحسين والإطلاق:** لوحات الإحصائيات، الاختبارات، الأداء، النشر.
